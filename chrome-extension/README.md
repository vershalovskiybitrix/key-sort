# Установка расширения

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `chrome-extension`.
4. Откройте настройки расширения «Key Sort — API Яндекса».
5. Для Wordstat укажите API-ключ Yandex Cloud с областью `yc.search-api.execute` и ID каталога.
6. Для прогноза бюджета укажите OAuth-токен приложения с доступом к API Яндекс Директа.

Секреты сохраняются в `chrome.storage.local`. Сайт получает только ответы выбранных методов и не получает значения ключей.
